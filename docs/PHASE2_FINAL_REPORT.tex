\begin{abstract}
ProtocolX Phase 2 extends the Phase 1 local network platform into a resilient, four-machine distributed architecture operating over a private campus LAN (\texttt{10.7.0.0/19}). Each team member configured, operated, and verified their assigned macOS node: Naveen (Primary DNS, TTL experimentation, and Central Control Center), Shagun (Nginx Edge Gateway, TLS 1.3 termination, and round-robin load balancing), Archit (Backend Worker A and Packet Filter isolation), and Aditya (Backend Worker B, Backup DNS, Standby Edge, and Packet Filter isolation). All six mandatory Phase 2 requirements (Tests A--F) passed live verification, and all four machines with six services reported \texttt{ONLINE} and \texttt{HEALTHY} on the Central Monitoring Dashboard.
\end{abstract}

\section{Executive Summary}
The team successfully deployed and verified the complete Phase 2 stack across four physical macOS laptops:
\begin{itemize}[noitemsep]
    \item \textbf{Redundant Private DNS:} Primary \texttt{dnsmasq} on Mac 1 (\texttt{10.7.11.221:53}) and Backup \texttt{dnsmasq} on Mac 4 (\texttt{10.7.18.164:53}) both resolve \texttt{app.protocolx.test} to \texttt{10.7.10.188} with a 30-second TTL.
    \item \textbf{Edge Gateway \& TLS 1.3:} Nginx (\texttt{1.31.10}) on Mac 2 terminates TLS 1.3, redirects HTTP to HTTPS, sets \texttt{Cache-Control: public, max-age=10}, and load-balances across Backends A and B.
    \item \textbf{High Availability \& Failover:} Passive health monitoring (\texttt{max\_fails=2 fail\_timeout=10s}, \texttt{proxy\_next\_upstream error timeout http\_502 http\_503}) transparently routes around backend outages and restores alternation after recovery.
    \item \textbf{Service Isolation:} macOS Packet Filter (\texttt{pfctl}) isolates ports \texttt{3001} and \texttt{3002} so only the Nginx Edge (\texttt{10.7.10.188}) can reach backend workers, with verified backup-and-restore rollback.
    \item \textbf{Standby Edge Migration:} Standby Nginx on Mac 4 (\texttt{:8443}) and live DNS cutover of \texttt{app.protocolx.test} were demonstrated and cleanly restored.
    \item \textbf{Hardened Control Center:} React + Vite + Express + Socket.IO + SQLite dashboard secured with salted \texttt{scrypt} hashes, \texttt{HttpOnly; SameSite=Strict} sessions, \texttt{X-CSRF-Token}, and single-use nonce replay protection.
\end{itemize}
